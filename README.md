# URL Shortener Service

Консольный сервис на Java 17 для создания коротких ссылок с лимитом переходов и сроком жизни.

## Требования

- JDK 17+
- Maven 3.8+

## Как пользоваться сервисом

1. Соберите проект:

   ```bash
   mvn clean package
   ```

2. Запустите приложение:

   ```bash
   java -jar target/url-shortener-service-1.0-SNAPSHOT.jar
   ```

3. При первом создании ссылки сервис автоматически создаёт пользователя и выдаёт его UUID.
   Все ссылки привязываются к текущему пользователю: он видит и может удалять только свои ссылки.

4. Настройки хранятся в `src/main/resources/application.properties`:

   | Параметр           | Описание                          | Значение по умолчанию   |
   |--------------------|-----------------------------------|-------------------------|
   | `link.base.url`    | Базовый адрес коротких ссылок     | `https://shrt.ly/`      |
   | `link.ttl.hours`   | Срок жизни ссылки в часах         | `24`                    |
   | `link.code.length` | Длина генерируемого короткого кода| `7`                     |

### Пример работы

```
========== МЕНЮ ==========
Текущий пользователь: не создан
1. Создать короткую ссылку
2. Мои ссылки
3. Перейти по короткой ссылке
4. Удалить короткую ссылку
5. Сменить пользователя
0. Выход
Выберите действие: 1
Введите исходный URL: https://example.com/page
Введите максимальное количество переходов: 5

Короткая ссылка: https://shrt.ly/aB3xY9z
Исходная ссылка: https://example.com/page

Действует до: 2026-11-15T12:00
```

## Поддерживаемые команды

| Пункт меню | Команда                          | Описание                                                              |
|------------|----------------------------------|-----------------------------------------------------------------------|
| `1`        | Создать короткую ссылку          | Принимает исходный URL и лимит переходов, возвращает короткую ссылку  |
| `2`        | Мои ссылки                       | Показывает ссылки текущего пользователя: код, переходы, статус, срок  |
| `3`        | Перейти по короткой ссылке       | Принимает короткий код или полную короткую ссылку, открывает браузер   |
| `4`        | Удалить короткую ссылку          | Удаляет ссылку, если текущий пользователь является её владельцем       |
| `5`        | Сменить пользователя             | Создаёт нового пользователя с новым UUID                              |
| `0`        | Выход                            | Завершает работу приложения                                           |

Правила работы ссылок:

- принимаются только URL со схемами `http` и `https`;
- лимит переходов должен быть больше нуля;
- после исчерпания лимита ссылка получает статус `LIMIT_REACHED`;
- по истечении срока жизни ссылка получает статус `EXPIRED` и удаляется при очистке;
- удалить чужую ссылку нельзя.

## Как протестировать код

Запуск всех тестов:

```bash
mvn test
```

Полная сборка с тестами и отчётом о покрытии:

```bash
mvn clean verify
```

Проверка стиля кода (Checkstyle):

```bash
mvn checkstyle:check
```

Рекомендуемый порядок перед коммитом:

```bash
mvn checkstyle:check && mvn clean verify
```

После тестов отчёт о покрытии доступен в `target/site/jacoco/index.html`.

Тесты расположены в `src/test/java`:

- `ShortLinkTest` — unit-тесты модели ссылки;
- `LinkServiceTest` — unit-тесты сервиса;
- `LinkServiceIntegrationTest` — сценарии полного жизненного цикла ссылки.

Те же проверки выполняются в CI (`.github/workflows/ci.yml`) при push и pull request в `main`.

## Структура проекта

```
src/main/java/
├── Main.java                 # консольное меню
├── LinkService.java          # бизнес-логика создания/использования ссылок
├── ShortLink.java            # модель короткой ссылки
├── LinkStatus.java           # статусы ссылки
├── User.java                 # пользователь (UUID)
├── AppConstants.java         # константы приложения
└── config/                   # загрузка настроек из application.properties
src/test/java/                # тесты (JUnit 5 + AssertJ)
```
